# 影词台 · 皮影戏方言唱本对齐与双语字幕工作台

非遗皮影戏字幕制作工具：把老艺人口述整理的**方言唱本**与**演出录音**自动对齐到句 / 字，
处理拖腔、锣鼓过门、道白、临场衬字与漏句，生成“方言大字 + 普通话释义”双语字幕，
支持波形拖动微调、SRT / WebVTT / ASS / JSON 导出，并可在浏览器里直接把硬字幕烧录进视频。

> 三出戏的方言唱词、普通话释义与录音均为本仓库**自编的演示数据**（关中方言风味的拟写，
> 非真实剧目录音），录音由 `src/audio/synth.ts` 按演出处理计划合成 PCM WAV。

## 快速开始

```bash
npm install
npm run dev          # 打开 http://127.0.0.1:5188
```

或直接使用已构建版本：

```bash
npm run build
npm run preview      # http://127.0.0.1:4188
```

## 四个页面（对应完整工作流）

1. **唱本导入**：三出自编示例戏（《借芭蕉扇》《王货郎卖线》《十八里相送》），
   也可粘贴 / 上传 `.txt` 唱本、上传录音或含音轨的视频。
   唱本格式：`【角色】（唱/白）方言唱词 || 普通话释义`，兼容 `角色(白): 台词`、`唱：…` 等。
2. **录音对齐**：对齐计算全部在 **Web Worker**（`src/workers/alignment.worker.ts`）中进行，
   带分阶段进度；可调节灵敏度与句间停顿阈值；内置“两小时全本性能自测”。
3. **字幕编辑**：
   - **Web Audio API** 解码 / 播放 / 试听，Canvas 绘制波形、时间标尺与过门底色；
   - 拖动字幕块两端竖柄改出入点、拖动块体整体移动、点击空白定位、空格播放暂停；
   - **唱本有但艺人没唱的整句 → 黄色卡片提醒**，可一键在播放头补配；
   - **临场加的衬字 → 灰色字 / 灰 chip**，可直接填成实际唱的字；
   - 拖腔超过 3 秒打 `拖腔 x.x s` 金标，尾点锁定到拖腔字结束之后，**字幕不会提前消失**；
   - **锣鼓过门 / 纯器乐段铺底色且不出字幕**，预览时显示“♪ 锣鼓过门 ♪”横幅；
   - 每行字数滑杆（8–24）自动断行，方言下方显示普通话行；逐字时间可查。
4. **导出烧录**：
   - **SRT**（UTF-8 BOM + CRLF，兼容 VLC / PotPlayer / 剪映 / PR / 电视）、
     **WebVTT**、**ASS**（方言 / 普通话两套样式）、**JSON**（逐字时间轴）；
   - 实时预览导出文本，可一次下载三种字幕；
   - **烧录面板**用 Canvas 实时渲染 1280×720 画面与字幕，`canvas.captureStream` +
     `MediaRecorder` 录制为 MP4（支持时）或 WebM；可上传底版视频，否则使用皮影幕布模板 + 该出录音。

## 对齐引擎原理（`src/alignment/engine.ts`）

纯函数、无外部模型，Node 与浏览器 Worker 共用：

1. 帧级特征：RMS 能量、过零率 ZCR、一阶差分高频比（帧长 / 帧移随采样率缩放）；
2. 锣鼓检测：高频比 + ZCR 的“明亮噪声音帧”经滑窗得分与形态学合并成锣鼓段，
   并排除锣尾余响，避免被当成唱字；
3. 音节切分：自适应能量阈值切出每个汉字的音节，超长持续音标为“长音”；
4. 短语划分：按句间静默分组；
5. **句级 DP**：唱本行 ↔ 音频短语，允许“漏句”（删行）与“外加乐句”；
6. **字级 DP**：行内唱字 ↔ 音节，允许“衬字”（跳音节，句首 / 句尾 / 短 / 音色暗成本更低）
   与“漏字”；多出来的超长音判为器乐过门；
7. 窗口策略：拖腔保持、最短可读时长、锣鼓 / 器乐强制留白、相邻字幕不重叠。

送入 Worker 前会把音频统一混为单声道并重采样到 22050Hz
（`mixToMonoResampled`），保证浏览器（AudioContext 常为 48kHz）与 Node 校验结果一致。

### 性能

复杂度约为 O(唱字数 × 局部带宽)。性能自测构造约 11900 唱字 / 340 句的两小时量级数据：
结构 DP 约百毫秒级，特征提取约数千倍实时，外推两小时全流程约 1–2 秒量级，远低于 5 分钟预算。
在“录音对齐”页可直接运行该自测。

## 自编录音与对齐校验

```bash
npm run gen:samples     # 由唱本 + perf 演出计划合成 public/samples/*.wav
npm run verify:align    # 用合成真值校验漏句/衬字/字边界/拖腔/锣鼓
npm test                # Vitest：断行、时间码、唱本解析、SRT 导出
```

`verify:align` 会断言：所有“漏唱句”被标黄、衬字数量与真值一致（±1）、
匹配字边界 MAE 与最大误差、>3s 拖腔字幕不提前消失、锣鼓段被检出且不与字幕重叠。
当前三出戏字边界 MAE 约 13–18ms。

## 说明与限制

- 这是一个**可离线运行的演示级对齐器**：不接 ASR，靠能量 / 音色特征与动态规整，
  对自编的干净合成录音效果很好；真实嘈杂录音或大段即兴可能需要更多人工拖动校正——
  这正是波形微调与黄 / 灰标记的用途。
- 浏览器烧录为**实时录制**（录制时长≈播放时长），样例每出约 1 分钟；
  两小时长视频建议导出 SRT/ASS 后用 ffmpeg / 剪辑软件压制。
- 推荐使用桌面版 Chrome / Edge 获得完整的 Worker、AudioContext 与 MediaRecorder 支持。
